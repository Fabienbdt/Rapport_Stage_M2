# Internship Report Images & Figures Directory

This directory contains all the figures, plots, diagrams, institutional logos, and result tables referenced in the M2 Internship Report (*Rapport de Stage M2*), its appendices, and associated presentations.

Most of the figures are organized by analysis campaign or model configuration (specifically transitioning from intermediate runs like `trial0017` to the final `stable_generalist` model).

## Directory Structure & Contents

### 1. Model Architectures & Pipelines
* **[SCRAW_PIPELINE](file:///data2/fbidet/Rapport_Stage_M2_git/Images/SCRAW_PIPELINE)**: Contains the main architecture diagram of the scRAW neural network (`scRAW.png`).

### 2. Biological Validation
* **[analyse_biologique_scraw_baron_stable_generalist](file:///data2/fbidet/Rapport_Stage_M2_git/Images/analyse_biologique_scraw_baron_stable_generalist)**: Biological evaluation of the final generalist model on the Baron Human Pancreas dataset. Includes:
  * Qualitative latent representations (`tsne_qualitative_panel.png`, `tsne_annotations_comparison.png`).
  * Marker gene overlap heatmap (`marker_overlap_heatmap.png`).
  * Source coordinates, cell type DEG lists, and validation metrics (`degs_top100.json`, `marker_overlap_matrix.csv`, `annotation_metrics_summary.csv`).
  * Python plotting scripts (`replot_figure_7.py`, `compare_annotations_projection.py`).

### 3. Inductive Learning Performance
* **[comparaison_inductive_scraw_stable_generalist_finale](file:///data2/fbidet/Rapport_Stage_M2_git/Images/comparaison_inductive_scraw_stable_generalist_finale)**: Final comparative boxplots and barplots for inductive learning metrics (ARI, NMI, ACC, BalancedACC, RareACC, UltraRareACC) across multiple test datasets (pancreas, testis, macaque retina, spleen, PBMC).
* **[comparaison_inductive_scraw_stable_generalist_synthese](file:///data2/fbidet/Rapport_Stage_M2_git/Images/comparaison_inductive_scraw_stable_generalist_synthese)**: Summarized inductive performance plots, including heatmaps, combined boxplots (`inductive_metrics_boxplots_ari_acc_rare_balancedrare_ultrarare.pdf`), and pre-formatted LaTeX tables (`inductive_dataset_metric_values_table.tex`) for report embedding.

### 4. Optuna Optimization & Hyperparameters
* **[hyperparametres_scraw](file:///data2/fbidet/Rapport_Stage_M2_git/Images/hyperparametres_scraw)**: Feature importance plots for three Optuna optimization campaigns:
  * `baron_param_importances_mean5_top30.png` (Campagne 1: Baron pancreas).
  * `generalist8_param_importances_mean5_top30.png` (Campagne 2: General optimization on 8 common datasets).
  * `stable_generalist_param_importances_mean5_top30.png` (Campagne 3: Consolidation search).

### 5. Multi-Method Benchmarking (Common-8 Datasets)
* **[scraw_common8_family_panel](file:///data2/fbidet/Rapport_Stage_M2_git/Images/scraw_common8_family_panel)**: Massive comparative panels and matrix heatmaps evaluating scRAW against other cell-clustering and batch-correction method families (Harmony, scanorama, Desc, PCA+Leiden, etc.). Contains LaTeX tables and Python generation scripts (`generate_common8_family_panels.py`).
* **[umaps_finales_8_datasets_sans_scraw_default](file:///data2/fbidet/Rapport_Stage_M2_git/Images/umaps_finales_8_datasets_sans_scraw_default)**: Final t-SNE / UMAP visualizations of the latent space for the 8 common datasets generated by the `stable_generalist` configuration.
* **[poids_reconstruction_stable_generalist_8_datasets](file:///data2/fbidet/Rapport_Stage_M2_git/Images/poids_reconstruction_stable_generalist_8_datasets)** and **[scraw_common8_stable_generalist_weights_reprojected](file:///data2/fbidet/Rapport_Stage_M2_git/Images/scraw_common8_stable_generalist_weights_reprojected)**: Visualizations of reconstruction and projection weights across methods and datasets.

### 6. Ablation Studies
* **[stable_default_mse_ablations_20260526_210436](file:///data2/fbidet/Rapport_Stage_M2_git/Images/stable_default_mse_ablations_20260526_210436)**: Ablation studies evaluating the contribution of each MSE loss term, triplet loss, and DANN alignment component. Includes the summary barplot (`stable_default_mse_ablation_key_metrics_barplot.png`) and parameters for each run configuration.
* **[scraw_loss_transfer_synthesis](file:///data2/fbidet/Rapport_Stage_M2_git/Images/scraw_loss_transfer_synthesis)**: Boxplots and LaTeX tables analyzing transfer loss variations (weighted vs. unweighted).
* **[scraw_loss_integration_matrix_stable_Default_20260504_135849](file:///data2/fbidet/Rapport_Stage_M2_git/Images/scraw_loss_integration_matrix_stable_Default_20260504_135849)**: Documentation matrix clarifying the loss function integration.

### 7. Evaluation & Validation (Misc.)
* **[scraw_stable_generalist_nonbaron](file:///data2/fbidet/Rapport_Stage_M2_git/Images/scraw_stable_generalist_nonbaron)**: Detailed QC summaries, error rate tables, and barplots on datasets excluding Baron human pancreas.
* **[scraw_holdout_validation](file:///data2/fbidet/Rapport_Stage_M2_git/Images/scraw_holdout_validation)**: Holdout validation barplots.
* **[umaps_finales_evaluation_finale_tous_datasets](file:///data2/fbidet/Rapport_Stage_M2_git/Images/umaps_finales_evaluation_finale_tous_datasets)**: Output manifests for all dataset UMAPs.
* **[comparaison_methodes_evaluation_finale](file:///data2/fbidet/Rapport_Stage_M2_git/Images/comparaison_methodes_evaluation_finale)** and **[comparaison_methodes_evaluation_finale_simplifiee](file:///data2/fbidet/Rapport_Stage_M2_git/Images/comparaison_methodes_evaluation_finale_simplifiee)**: Secondary evaluation comparison tables and figures.

### 8. Streamlit Benchmark UI (SCRBenchmark)

  * UI Screenshots (`scr_01_upload.png` to `scr_09_resultsUmaps.png`) illustrating the application workflow (file upload, data visualization, preprocess, algorithm choice, execution, and UMAP results plotting).
